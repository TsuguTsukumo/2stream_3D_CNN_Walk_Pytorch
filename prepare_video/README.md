# `prepare_video`

Canonical video preprocessing package.

This package is maintained for the ASD vs non-ASD study.

- Positive class: `ASD`
- Negative class: `ASD_not` in the final folds
- Raw inputs are synchronized `full_ap.mp4` and `full_lat.mp4`
- Raw non-ASD sessions may be stored as `non-ASD`, `DHS`, `LCS`, `HipOA`, etc.
- `右足`, `左足`, `固定無し` are not the recommended dataset labels for this pipeline
- `front.mp4` and `side.mp4` are generated by preprocessing
- The maintained entrypoint is `python -m prepare_video ...`; standalone legacy scripts are reference code only

Use the module entrypoint:

```bash
python -m prepare_video --help
```

Available commands:

- `preprocess`
- `split`
- `balance`
- `rename`
